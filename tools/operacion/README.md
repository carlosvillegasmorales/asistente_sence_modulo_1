# Scripts de operación de los servidores

Esta carpeta está en `.gitignore` (solo se versiona este README): los scripts de aquí llevan o
pueden llevar credenciales del servidor y **no deben subirse a Git**. Cada persona que administra
los VPS tiene su copia local. Si hace falta compartir un script, primero debe leer las credenciales
de variables de entorno (ver `deploy/.env.example`).
